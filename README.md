## Мини-CRM для сбора и обработки заявок с сайта через универсальный виджет.


### Инсталяция и запуск
1) Склонируйте git репозиторий с Мини-CRM, например командой:<br> 
git clone https://github.com/jon1267/it-grp.git
2) В терминале запустите команду: composer install.
3) Вам необходимо создать файл .env, с соответствующими настройками вашей БД. 
4) Для этого скопируйте файл .env.example в файл с именем .env, измените настройки.
5) Запустите команду: php artisan key:generate.
6) Запустите команды: npm install и npm run dev.
7) Запустите команду: php artisan migrate:fresh --seed, для создания БД 
и заполнения ее тестовыми данными.

После этого, если все прошло без ошибок, Мини-CRM готова к запуску.

### Тестовые данные, роуты, пользователи
1) Сидеры Мини-CRM создают двух тестовых пользователей с такими именами/паролямии:<br>
 - Admin
 - email: admin@example.com,
 - password: password<br><br>
 - Manager
 - email: manager@example.com,
 - password: password

2) Также сидеры создают тестовых заказчиков, заявки, роли, разрешения для ролей.

3) Для создания заявки, нужно пройти по роуту https://your-site.local/widget,<br> 
где your-site.local - имя вашего локального домена (сайта).

4) Статистика по заявкам, доступна по Api маршруту<br>
https://your-site.local/api/tickets/statistics

5) Для встраивания виджета на другие сайты, через iframe поместите код<br>

  <iframe 
    src="https://your-site.local/widget"
    width="800px" 
    height="800px"
    style="border:none;" 
  ></iframe>

  в html коде нужной вам страницы, в любом месте, внутри тега body.

### Админ панель Мини-CRM
1) В качестве админ панели (админки) для Мини-CRM использовался Filament v5.<br>
2) Для входа в админку используйте маршруты  
https://your-site.local/admin либо https://your-site.local/admin/login
3) Вход в админку доступен тестовым пользователям админ и менеджер, указанным выше<br>
(а именно: admin@example.com, password и manager@example.com, password)
4) Решение прменить Filament, принял исходя из его популярности, распространенности,<br>
и обширного базового функционала. Просмотр списка заявок, сортировка и фильтрация<br>
по различным полям, просмотр деталей заявки, фактически встроены в филамент из коробки.
